# Nossa regra

Toda funcionalidade nova deve responder:

Ela economiza tempo?

Ela reduz erros?

Ela aumenta vendas?

Ela melhora a experiência?

Se não responder positivamente a pelo menos uma dessas perguntas, ela deverá ser reavaliada.
