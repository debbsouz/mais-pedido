# VISÃO DO +PEDIDO

## Nossa visão

O +Pedido não será apenas um sistema de pedidos.

Queremos construir a principal plataforma de gestão para restaurantes da América Latina.

O objetivo é que qualquer estabelecimento consiga administrar seu negócio utilizando apenas o +Pedido.

---

# Onde queremos chegar

## Curto prazo

Lançar uma primeira versão estável.

Permitir que restaurantes recebam pedidos de forma simples.

---

## Médio prazo

Ter centenas de estabelecimentos utilizando a plataforma.

Implementar IA para automações.

Aplicativo Windows.

Aplicativo Android.

---

## Longo prazo

Ser referência nacional em tecnologia para restaurantes.

Ter milhares de clientes ativos.

Disponibilizar APIs públicas.

Marketplace de integrações.

Ecossistema completo.

---

# Nossa missão

Economizar tempo.

Reduzir erros.

Aumentar vendas.

Automatizar processos.

---

# Nossa filosofia

Sempre perguntar:

"Como podemos fazer isso com menos cliques?"

"Como podemos automatizar essa tarefa?"

"Como podemos facilitar a vida do restaurante?"

---

# Nossos valores

Simplicidade

Velocidade

Qualidade

Segurança

Inovação

Experiência do usuário

---

# Nosso compromisso

Nunca adicionar funcionalidades apenas para "encher o sistema".

Toda funcionalidade deve resolver um problema real.
